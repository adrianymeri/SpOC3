# Extra-instance benchmark — 13 HC variants × 20 random graphs

Random Erdős-Rényi graphs spanning 5 sizes × 4 densities.  Budget per (algo, instance) = 1 s wall, seed = 42.  Scores are −HV (more negative is better; "—" = the warm start itself produced an over-width permutation and the archive stayed empty).

Numbering follows the post-renumber convention: **hc2 = initial baseline, hc3 = single-objective simple, hc4 = archive, hc5 = warm start, hc6 = operators (incl. 2-opt / 3-opt), hc7 = gap-fill, hc1 = K-bottleneck, hc8 = LAHC, hc9 = HV-acceptance, hc10 = torso-aware warm start, hc11 = ILS, hc12 = incremental evaluator, hc13 = tabu**.  hc14 (steepest-ascent) is not in the 20-instance benchmark.
