# submissions/

ESA-format submission JSONs, one folder per instance
(`small-graph/`, `medium-graph/`, `large-graph/`). Layout:

```
submissions/<instance>/
  <method>.json        canonical per-method submissions (hc1..hc15, grasp, sa,
                       vns, aco, nsga2, sms, sms_ls, cmaes, ...) + portfolio.json
  seeds/
    <method>_s<N>.json per-seed sweep outputs (grasp_s26, cmaes_s4, cmaesf_s6,
                       sms_ls_s19, ...). These are the multi-seed provenance the
                       portfolio unions over; kept out of the flat dir so the
                       ~20 canonical methods stay legible.
```

**Routing is automatic.** `core.submission_path()` sends any stem ending in
`_s<digits>` into `seeds/`; everything else stays flat. `tools/portfolio.py`
scans both. So a runner invoked with `--algo cmaes_s4` lands in `seeds/`, and
`--algo cmaes` (or `hc9`, `grasp`, ...) stays flat — no caller changes needed.

**`portfolio.json`** is the instance-specific best-of: the top-20-by-HV union
of every method + seed, regenerated by `python3 tools/portfolio.py`. It is the
submission to use. Current scores (canonical-verified, 0 capped):
small −1,828,063 · medium −1,704,738 · large −5,369,684.

Throwaway tuning stems (`*_tune`) are never pooled by the portfolio.
